# ara-render2d

Owned Vulkan 2D render path, built on ara-gpu and ara-render's graph/capture/post.
API: AtlasImage, Scene2d, SpriteDraw, Renderer2d, Scene2d::extract, capture.
Scene2d is an immutable extraction product, never authoritative gameplay state.
Sprites use procedural instancing, bindless images and stable painter sorting.
Nine-slice uses 54 procedural vertices, ordinary sprites six. Tile layers are split
into immutable 32x32 draw batches and culled as chunks. Sorting never batches across
an intervening order key. Pixel mode snaps camera/positions and uses nearest texels.
Texture payload AR2A v1 is decoded without native struct casts. Color images use
SRGB, normal maps use UNORM. Lighting/shadow tests run only for opt-in lit sprites.
Main renderer ToneMap is reused; pixel mode never applies jitter or TAA.
Capture uses shared marks/picking/provenance. Supported 2D debug views are lit,
albedo, normals, entity_ids and shadow_cascades (shadow visibility).
Cook shaders offline; never invoke a compiler from the runtime or build.rs.

Set CARGO_BUILD_JOBS=2. run.ps1 scopes the Vulkan implicit-layer workaround.
Run ./run.ps1 -Mode Check, -Mode Cook, -Mode Capture, or -Mode Benchmark.
Check runs cargo check/test/clippy (--all-targets -D warnings), fmt --check for
all four 2D crates and the additive GPU/render hooks. Goldens require this PC's
Vulkan SDK validation layer; ARA_UPDATE_2D_GOLDENS=1 deliberately updates references.
Baseline .rgba assets and canonical .scene files are generated by the sample
example only when requested; normal golden tests never overwrite references.
