Add an icon: download `<name>.svg` from that commit into this folder, then run
`cargo run -p ara-kit --example gen-icons` to regenerate `src/icons.rs`.

`folder-full.svg` is Ara's own (Lucide's folder with two content lines, same grid and stroke):
the Assets view tells a folder with contents from an empty one by shape, not colour, so
folder colours can stay a user choice.
