The shared contract defines this name once; `@path#id` and the marker's `main` resolve relative to `content/`, without that prefix. Any exact lowercase `editor` ancestor marks C# as editor-only and compiled separately. An optional lowercase `<name>.module.json` defines a module boundary; other scripts join the default game module. Versioned project policy lives under `settings/`, with build/export presets in `settings/builds/`. Generated projects, assemblies, schema, caches, per-user state and logs live in gitignored `.ara/`; output lives in gitignored root `builds/`. Root `packages/` is reserved for future plugins/packages and excluded from authored discovery until plugins exist (D22). Repository sample tests and evidence live outside game projects. `ara project migrate --dry-run` previews moving legacy type folders, root scripts and earlier `assets/` or `game/` drafts into `content/`, preserving IDs, references, empty folders and history; the resulting marker records `layoutVersion: 4` and pins the migrating engine. Engines declare supported layouts through `ara --json capabilities`; no declaration means v3-only. The Hub blocks an incompatible v4 pin with Use/Install current engine or Cancel; old v3 projects may still use old engines until migrated. Export reports, verification/debug artifacts, logs and symbols stay outside the shipped folder. Distribution manifests remain store-agnostic (D22). ## Architecture (adopted from research)

These are working decisions. A spike result or a new entry here can change them.

| ID | Decision | Source |
|---|---|---|
| A1 | **Object model.** Entities in a hierarchy with plain reflected components in `bevy_ecs`. *Behaviours* are per-entity C# objects that hold no authoritative state; *Systems* are batched queries with declared reads/writes, scheduled in parallel. Prefab overrides are addressed by ID. | R01, R10 |
| A2 | **Schema DB is the single source of truth.** Rust derives and C# source generators feed it. It carries units, ranges, required docs and replication policy, and generates serialization, the inspector, bindings, JSON Schema, the MCP catalog, docs and net codecs. Implemented in M1 as an Ara-owned `#[derive(Schema)]` (crates `ara-schema` + `ara-schema-derive`), independent of bevy_ecs; `bevy_reflect` is optional for runtime inspection once ECS lands. | R01, R03, R07, M1 |
| A3 | **Files.** Canonical strict JSON; defaults omitted; a flat entity map keyed by short IDs; `@path#id` references; `ara fmt` and `ara merge`. Binary only for source media. Derived data lives in a content-addressed cache. | R01, R03 |
| A4 | **Mutation.** Typed command → validated ops with automatic inverses → transaction attributed to a human or an agent. Agent edits apply live but are shown as unreviewed until accepted or reverted. Network gameplay commands are intents, never edits. | R01, R03, R04, R09 |
| A5 | **Engine Protocol.** JSON-RPC 2.0 over WebSocket/stdio, localhost plus token; the editor uses it too. A generated MCP adapter exposes about 12 tools. | R01, R03 |
| A6 | **Processes.** One engine library; `ara editor`, `ara` (CLI/daemon) and `ara-player`. Play mode runs in a child process. Importers are pure functions in worker processes. | R01, R03, R04 |
| A7 | **UI stack.** Retained tree; Taffy layout; Parley text, with HarfBuzz via FFI wherever coverage is missing; engine display lists; AccessKit. HTML-like markup plus a CSS-subset stylesheet with typed C# bindings. Focus and input in the style of Unreal's CommonUI. | R05, R07, R10 |
| A8 | **Rendering.** SM6.6-style bindless; explicit render-graph barriers; multi-queue. Slang → SPIR-V, and Slang → DXIL → Metal Shader Converter → metallib. One material AST with a text view and a graph view. Tiers: RT, Raster, Mobile; baked/probe lighting is mandatory as the fallback. | R02, R08 |
| A9 | **Platform layer:** SDL3 via `sdl3-sys`. | R08 |
| A10 | **Multiplayer.** Server-authoritative snapshots, interpolation and selective owner prediction. Sessions: Local (zero serialization), Listen, Dedicated. Lightyear + Replicon evaluated behind our schemas. | R09 |
| A11 | **Reuse.** Bevy 0.20 crates (no fork). Kira and Steam Audio; gltf, ufbx, meshopt, KTX2; Recast; Tracy; Sentry minidumps. | R06, R07 |
| A12 | **Performance tiers (DOTS-class).** Engine systems and hot gameplay systems in Rust are the "Burst tier": the same LLVM backend, with `&mut` giving no-alias guarantees and SIMD via `glam`. C# systems run over chunk-batched spans with no per-entity calls, using explicit SIMD (`Vector128`/`Vector256`) and NativeAOT in shipping builds. A compiler for a C# subset through LLVM is in the build order, decided by the S8 benchmarks. | R07, R10 |
| A13 | **C# hosting and reload (from S2).**<br>• Hosting: Rust hosts .NET via hostfxr in dev, with `Ara.Runtime` in the default ALC. One generated, layout-hashed `#[repr(C)]` ABI (`HostInit` + `HostApi` + `ScriptApi`); C# bindings are generated from Rust descriptors.<br>• Every entry point is `[UnmanagedCallersOnly]` and catches everything.<br>• Systems: one call per contiguous ECS batch, from Bevy task-pool threads, addressed by id into a C# table swapped only at tick boundaries. Rust never holds pointers into module code.<br>• Reload: **L1** (EnC body-only edits; any method containing a lambda or local function, a constructor, an initializer or a state machine escalates to L3, because a lambda delta crashed the process) or **L3** (a new collectible ALC per module generation).<br>• Runtime config: `QuickJitForLoops=false` (otherwise tiered compilation pins ALCs), `MetadataUpdaterSupport=true`.<br>• **Roslyn runs in a warm out-of-process compile server** (no compiler GC hitches in the game), and tick threads run at above-normal priority while it compiles. | S2, R10 |

## Development Rust reload (S11)

**A14 (2026-10-27):** opt-in development Rust hotpatching uses Dioxus Subsecond
and Bevy ECS's experimental hotpatching dispatch. Publish at quiescent frame/tick
boundaries, preserve last-good code on rejection, and rebuild for data-layout or
unsupported retained-code changes. Patched simulation sessions are explicitly
tainted for replay/networking. Shipping/export players exclude this feature.
The Windows rust-lld facade and initial Windows/Mac evidence are in
[`S11`](../spikes/s11-rust-hotpatch/RESULT.md). This does not change D17's toolchain
or add dx as a build prerequisite. Actual engine-path latency is not measured yet.
