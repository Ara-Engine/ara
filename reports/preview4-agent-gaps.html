Design calls

  1. Editor extensions are an editor-only assembly domain. Ara.Editor supplies command/menu registration and immutable invocation snapshots. Background callbacks return existing typed commands; the authority commits one attributed cmd.apply batch. Menu, palette, shortcuts and protocol discovery share the native registry. Agent selection remains private. Failed reloads retain the last good generation; a fault discards the callback's queued operations and disables that callback until a changed successful reload.
  2. Runtime reparenting keeps local transforms. Commands.SetParent applies at the normal ECS sync point and validates cycles before undo mutates anything. Authoring reparenting uses the existing typed entity command and its semantics.
  3. Destruction is observed at the next fixed-tick membership sweep. OnDestroy runs once after a behaviour component or its entity disappears, ordered by module, type and ascending generation-checked handle, including when the last instance is removed. Removed data is unavailable; other live ECS data remains accessible. Reload uses OnReload. No synthetic shutdown tick is introduced. ABI 4 means host, player and SDK artifacts must ship together.
  4. File state is shared, immutable and reversible. Content-addressed byte tokens and explicit empty-directory/absence states live in .ara/file-history/. Commands perform no I/O. Prepared inventories include complete directory membership and opaque owner metadata, with worker revalidation before authority commit. Case-key policy is shared with planners; Windows junction/reparse checks repeat during restore. Missing ancestors are recorded as absent so redo can recreate folders safely.
  5. Source authoring uses the same primitive. source.replace {path, baseHash, text, from?} creates a checked-absent source when the base is null, edits an exact base version, or relocates and replaces it in one transaction. Native create/rename, compatibility script.write and analyzer fixes all use it. Source jobs finish after materialization acknowledgment.
  6. CLI preparation waits for progress. The default stall budget is 120 seconds, configurable through ARA_JOB_STALL_TIMEOUT_SECS. Fraction or phase changes reset it; unrelated heartbeats do not. Total progressing duration has no fixed cutoff. ARA1815 identifies a stalled job and its last phase.
  7. The module inventory owns discovery and generated outputs. Rust passes ara_doc::AUTHORING_ROOT to the shared compiler inventory. Exact editor ancestors form editor-only assemblies; named references, unknown references and cycles are checked. Private outputs stay in .ara/scripts/; publication is serialized across preparation workers. Open/check/export publish schemas before validation, and moving across module/editor boundaries refreshes membership and validates the candidate before restarting Play.
